# World Happiness Report | Power BI Dashboard

## 📌 Project Overview
This project analyzes World Happiness Report data using Microsoft Power BI. The dashboard explores happiness scores across countries and compares different indicators to understand variations in reported happiness.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** — Dashboard development and visualization
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and calculations

## 📊 Key Analysis
- Country-wise Happiness Score Analysis
- Happiness Score Comparison
- Regional Happiness Trends
- Comparison of Available Happiness Indicators
- Interactive Filtering and Data Visualization

## 🎯 Project Objectives
- Compare happiness scores across countries.
- Explore differences between regions.
- Understand patterns in the available happiness indicators.
- Present the findings through interactive visualizations.
